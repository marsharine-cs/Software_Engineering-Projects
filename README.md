# JavaScript Knowledge Quiz

An interactive educational web application designed to test and reinforce foundational JavaScript concepts through ten multiple-choice questions, immediate feedback, explanations, progress tracking, scoring, and answer review.

This project combines **JavaScript application development with instructional design**, demonstrating how front-end technology can be used to create an engaging learning and assessment experience.

## ⚙️ How the Application Works

### 1. Question Data

Quiz questions are stored as JavaScript objects inside an array.

Each question contains:

```text
category
question
answers
correct answer
explanation
```

### 2. Dynamic Rendering

JavaScript dynamically displays the current question and creates the answer buttons.

The interface updates automatically as the user progresses through the quiz.

### 3. Answer Feedback

After an answer is selected:

* the answer is stored
* the correct answer is identified
* visual feedback is displayed
* an explanation of the concept appears
* the question becomes locked

### 4. Progress Tracking

The application calculates quiz progress based on the current question and updates both:

* the progress percentage
* the visual progress bar

### 5. Scoring

After the tenth question, JavaScript compares the user's answers with the correct answers and calculates the final percentage.

### 6. Answer Review

Users can review all ten questions after completing the quiz to compare their selections with the correct answers and study the explanations.

### 7. Retake Quiz

The Retake Quiz feature resets the application state and allows the user to begin again.
