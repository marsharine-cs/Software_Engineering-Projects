# AI Development Field Guide

## From Fundamentals to Generative AI

The **AI Development Field Guide** is an interactive technical documentation project designed to explain how modern artificial intelligence systems are understood, developed, evaluated, and improved.

The project combines **front-end development, technical writing, educational design, and AI/ML concepts** in a responsive learning experience built for developers, technologists, students, educators, and anyone exploring artificial intelligence.

---

[View AI Development Field Guide](https://ai-development-field-guide.vercel.app/)

## 📌 Project Overview

Artificial intelligence covers a wide range of concepts, tools, and development practices. This project organizes those ideas into a structured field guide that allows users to either follow a recommended learning path or jump directly to a topic they need.

The guide explores the full AI development process—from defining a problem and preparing data to understanding machine learning, generative AI, prompt engineering, Retrieval-Augmented Generation, evaluation, and responsible AI.

Rather than presenting the material as a static article, the project uses interactive documentation features to make the learning experience easier to navigate and more engaging.

## 🧭 Guide Sections

### 1. Overview
Introduces the AI Development Field Guide and provides a high-level view of the topics covered.

### 2. Learning Path
Organizes AI development into a practical sequence:

1. Understand the problem
2. Understand the data
3. Learn from patterns
4. Work with generative systems
5. Evaluate results
6. Consider responsible use

### 3. AI Fundamentals
Explains the relationship between:

- Artificial Intelligence
- Machine Learning
- Deep Learning
- Generative AI

### 4. AI Development Workflow
Introduces a practical development cycle:

- Define
- Gather
- Prepare
- Build
- Evaluate
- Improve
- Monitor

### 5. Machine Learning
Explores major machine-learning approaches:

- Supervised learning
- Unsupervised learning
- Reinforcement learning
- Training, validation, and testing

### 6. Generative AI
Explains how generative systems receive context, process information, and produce new outputs such as text, code, images, and other artifacts.

The section also introduces important strengths and limitations of generative systems.

### 7. Prompt Engineering
Explores a practical prompt structure based on:

- Task
- Context
- Constraints
- Audience
- Output format

It also compares weak and stronger prompt examples.

### 8. Retrieval-Augmented Generation
Introduces **RAG** and demonstrates a simplified workflow:

1. User question
2. Retrieve relevant information
3. Add context
4. Generate a response

### 9. Model Evaluation
Explores important evaluation dimensions including:

- Correctness
- Relevance
- Reliability
- Human judgment

### 10. Responsible AI
Introduces several important considerations for responsible AI development:

- Privacy
- Fairness
- Transparency
- Security
- Human oversight
- Accountability

### 11. AI Glossary
Provides quick definitions of common AI terminology, including:

- Algorithm
- Dataset
- Embedding
- Generative AI
- Inference
- Machine Learning
- Model
- Neural Network
- Prompt
- RAG
- Token
- Training

## 🧠 Interactive Learning Features

### Documentation Search

Users can search the guide from the documentation sidebar.

The search system indexes:

- section titles
- keywords
- visible documentation content

Pressing `/` anywhere on the page moves keyboard focus directly to the search field.

---

### AI Concept Explorer

The AI Fundamentals section contains expandable concept cards that help users compare major AI terms without overwhelming the page with information.

---

### Copyable Code Examples

Code and prompt examples include **Copy** controls so users can quickly reuse examples.

The project includes a clipboard fallback for environments where the modern Clipboard API is unavailable.

---

### Searchable Glossary

The glossary can be filtered in real time.

As the user types, the interface:

- hides non-matching terms
- searches both terms and definitions
- updates the visible term count

---

### Reading Progress

A progress indicator at the top of the page provides a visual representation of how far the user has moved through the guide.

---

### Theme Switching

Users can switch between **light and dark themes**.

The selected theme is stored locally so the preference remains after the page is refreshed.
