## 🔧 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/marsharine-cs/Software_Engineering-Projects.git
```

### 2. Enter the repository

```bash
cd Software_Engineering-Projects
```

### 3. Switch to the Projects Portfolio branch

```bash
git checkout Projects-Portfolio
```

### 4. Open the website

Open `index.html` in your preferred web browser.

You can also open the project directory in Visual Studio Code and use a local development server if preferred.
