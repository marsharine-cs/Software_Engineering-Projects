BEHIND THE CODE

How it works

The checker normalizes the text before comparing it with its reversed form.

01

Normalize

JavaScript converts the text to lowercase and removes spaces, punctuation, and special characters.

02

Reverse

The cleaned text is split into characters, reversed, and joined back together.

03

Compare

The original normalized text is compared with the reversed version to determine the result.
