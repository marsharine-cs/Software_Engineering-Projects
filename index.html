03

FOUNDATIONS

Start with the vocabulary.

These terms are related, but they do not mean the same thing. Understanding the hierarchy makes the rest of AI development easier to reason about.

Artificial intelligence is the broad field concerned with creating computational systems that perform tasks associated with human-like reasoning, perception, learning, language, or decision-making.

Think of it as: The broadest umbrella.

Machine learning is an approach in which systems improve task performance by finding useful patterns in data rather than relying only on manually written rules.

Think of it as: Learning useful patterns from examples.

Deep learning uses multi-layered neural networks to learn increasingly complex representations from data.

Think of it as: A powerful family of machine-learning techniques.

Generative AI refers to systems designed to produce new outputs such as text, images, audio, code, or structured content based on learned patterns.

Think of it as: Models that generate new content.

04

DEVELOPMENT WORKFLOW

Good AI starts before the model.

The quality of an AI system depends on more than choosing an algorithm. Strong development begins with the problem and continues through evaluation and monitoring.

01

Define

Clarify the problem, expected outcome, constraints, users, and success criteria.

02

Gather

Identify useful data and understand its origin, quality, limitations, and permissions.

03

Prepare

Clean, transform, structure, and inspect data before modeling.

04

Build

Select an appropriate approach and create the initial model or system.

05

Evaluate

Measure performance against meaningful criteria rather than relying on impressions.

06

Improve

Diagnose weaknesses, adjust the system, retest, and continue iterating.

07

Monitor

Observe real-world performance, failures, changing data, and unintended outcomes.

CONCEPTUAL PYTHON

A simple preprocessing mindset 

def prepare_records(records):
    cleaned = []

    for record in records:
        if record is None:
            continue

        value = str(record).strip().lower()

        if value:
            cleaned.append(value)

    return cleaned

Development principle

A sophisticated model cannot automatically repair a poorly defined problem or unreliable data pipeline.

05

MACHINE LEARNING

Learn from patterns in data.

Machine-learning approaches differ according to the type of information available and the task the system must perform.

A

LABELED EXAMPLES

Supervised Learning

The system learns relationships between examples and known target outcomes.

  • Classification
  • Regression
  • Prediction
B

UNLABELED PATTERNS

Unsupervised Learning

The system explores structure or relationships without predefined target labels.

  • Clustering
  • Pattern discovery
  • Dimensionality reduction
C

FEEDBACK

Reinforcement Learning

An agent learns behavior through interactions and feedback associated with its actions.

  • Actions
  • Rewards
  • Policies

MODERN AI

Systems that generate.

Generative systems create new outputs by modeling patterns learned from large collections of examples.

01 Input

Prompt, image, audio, structured data, or other context.

→
02 Model

Processes context and predicts useful output patterns.

→
03 Output

Text, code, image, audio, or another generated artifact.

STRENGTHS

Useful for exploration.

  • Drafting and ideation
  • Information synthesis
  • Code assistance
  • Structured transformation
  • Natural-language interaction

LIMITATIONS

Output still requires judgment.

  • Generated information may be inaccurate
  • Context can be misunderstood
  • Bias may be reflected in results
  • Sensitive information requires care
  • Important decisions need verification

RETRIEVAL-AUGMENTED GENERATION

Give the model relevant information first.

Retrieval-Augmented Generation, commonly called RAG, combines information retrieval with generation so a system can use relevant external material when constructing an answer.

RESPONSIBLE AI

Capability is not the only question.

Responsible development also considers whether a system should be used, who may be affected, and what safeguards are appropriate.

01

Privacy

Protect sensitive information and understand what data is being collected, stored, or shared.

02

Fairness

Examine whether system performance differs unfairly across people, populations, or contexts.

03

Transparency

Make important limitations and system behavior understandable where appropriate.

04

Security

Consider misuse, unauthorized access, manipulation, and other technical risks.

05

Human Oversight

Keep people appropriately involved when consequences are significant or judgment is required.

06

Accountability

Define who is responsible for system design, deployment, monitoring, and correction.

Responsible AI asks not only “Can we build it?” but also “How should it be used?”

12 terms
Algorithm
A defined procedure or set of computational steps used to solve a problem.
Dataset
A structured collection of examples or information used for analysis or model development.
Embedding
A numerical representation designed to capture meaningful relationships between items.
Generative AI
AI systems designed to produce new content such as text, images, audio, or code.
Inference
The process of using a trained model to produce a prediction or output.
Machine Learning
A family of methods that learns useful patterns from data.
Model
A computational representation learned or configured to perform a specific task.
Neural Network
A computational architecture composed of connected processing units organized into layers.
Prompt
Input or instructions provided to a generative AI system.
RAG
Retrieval-Augmented Generation combines retrieved information with generative model output.
Token
A unit of text representation processed by many language-model systems.
Training
The process in which a model adjusts its internal parameters using examples or feedback.
